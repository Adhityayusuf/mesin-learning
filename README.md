# Mesin Learning

Catatan praktikum **Mesin Learning** (Machine Learning) — kumpulan
notebook Jupyter yang dikerjakan di **Google Colab**, tiap jobsheet
punya folder sendiri.

## Struktur

| Folder | Isi |
|--------|-----|
| `JS02/` | Jobsheet 2 — 4 notebook praktikum + 1 tugas |
| `JS03/` | Jobsheet 3 — 3 notebook praktikum |
| `JS04/` | Jobsheet 4 — 1 notebook praktikum |
| `JS05/` | Jobsheet 5 — 1 notebook praktikum |
| `JS06/` | Jobsheet 6 — 3 notebook praktikum |
| root | `KUIS1_244107020045_M_Adhitya_Yusuf_Al_Ayyubi.ipynb` — Kuis 1 |

Setiap notebook punya badge **Open in Colab** di baris pertama — klik
badge itu untuk langsung membukanya di Google Colab tanpa install
apa pun.

## Library yang Dipakai

- **Data:** pandas, numpy
- **Machine Learning:** scikit-learn, TensorFlow
- **Visualisasi:** matplotlib, seaborn
- **Gambar:** OpenCV (cv2), Pillow (PIL), SciPy
- **Dataset:** ucimlrepo (UCI Machine Learning Repository)
- Lainnya: ipywidgets, mpl_toolkits

## Cara Menjalankan

1. Buka notebook lewat badge Colab, atau
2. Jalankan lokal:

```bash
pip install jupyter pandas numpy scikit-learn tensorflow matplotlib seaborn opencv-python pillow scipy
jupyter notebook
```
